设备检测到桌面 Word 与 PowerPoint。真实 Office 集成测试在生成旧格式样本时超时，尚未形成成功的原生转换与同步证据。因此本次验证只确认基础网页功能和 Windows 适配器的回归行为，不将 COM 转换声明为本机实测通过。

Word/PowerPoint 的首次初始化、授权、加载项或弹窗可能需要用户先处理。MathType 写回、OMML 转 MathType 和 Word 宏执行仍需独立适配器；默认客户端不报告这些能力可用。
