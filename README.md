# K12 文档智能处理工具

最后维护时间：2026-06-25 17:02:53 CST

K12 是一个本地优先的文档处理工作台原型，按 PRD 覆盖 Word、Excel、PPT、PDF 的上传识别、任务队列、公式预检、OMML 能力位、宏编排、微小图片检索、报告导出和本地/网页混合模式状态。

当前版本使用 Python 标准库后端和静态前端，不依赖外网安装包。Office、MathType、OMML 转换、Word 宏执行等强本机能力被封装为清晰的本地客户端能力位，便于后续按 Windows 与 macOS 分别接入本地处理服务。

## 运行

```bash
make run
```

打开：

```text
http://127.0.0.1:8765
```

## 测试

```bash

```

## 项目结构

```text

tests/            标准库 unittest 测试

```

- 拖拽上传真实文件到本地 `.k12-data/uploads/`，ZIP 上传后自动识别压缩包内支持的文档条目。

- 任务中心支持按任务打包下载 ZIP，包含任务 JSON、日志、报告和转换输出。

## Mathpix PDF 转 Word

PDF 转 Word 的识别引擎设置为 Mathpix。出于 PRD 的隐私和第三方上传安全要求，系统不会默认上传文件；需要在设置页开启“授权外部上传”，并在运行服务的环境里配置：

```bash
export MATHPIX_APP_ID="你的 APP ID"
export MATHPIX_APP_KEY="你的 APP KEY"
```

运行预检会检查上述环境变量是否存在，只展示环境变量名，不回显 APP ID 或 APP KEY 的实际值。

如果开启“等待识别完成”，任务会轮询 Mathpix 状态并在完成后下载 DOCX 到当前输出目录的 `{task_id}/` 子目录，同时保存 Mathpix `tex.zip` 公式识别结果包。DOCX 和公式包都会写入标准转换输出，可在任务中心直接下载或随任务结果包一起打包。系统还会从 Mathpix 的 `.tex` 文件中提取 PDF 公式，写入公式报告和统一公式导出包。

每个 Mathpix PDF 作业都会记录 `retention_plan`，包含 PDF 类型、图片对象数、表格线索、公式线索、文字/公式/表格 OCR 开关，以及图片、表格、公式的保留状态。外部上传未授权时也会生成该计划用于报告复核，但不会提交 PDF。

## OMML 依赖检索

Word 文档检测到 OMML 公式后，文件列表会显示“OMML缺失”状态。`公式预检`、`OMML 转 MathType`、`Word 转 PPT` 和 `MathType 格式化` 任务会写入“OMML 转换确认”记录，标明是否已选择转换为 MathType、是否保留原公式、决策来源和依赖状态；未确认时本地客户端载荷会保持等待确认。任务会尝试查找 `OMML2MML.XSL` 等 OMML 依赖文件。检索范围包括当前文档目录、K12 运行目录、常见用户目录和设置页填写的自定义路径；也可以在设置页手动指定一个 OMML 依赖文件。复制策略支持覆盖、跳过和自动重命名。

## Word 宏安全队列

宏处理默认不会在网页端直接执行 Word 宏。用户可以在宏页选择宏并调整顺序，把常用顺序保存为模板，确认风险后创建任务；系统会先备份本地 Word 文件，然后把宏队列写入报告，状态标记为“待本地客户端执行”。后续接入 Windows 本地客户端后，可由本地 Office COM 执行队列。

设置页可以关闭宏检测、关闭宏执行队列、按当前文档宏/模板宏/本地宏库分别授权，或启用“仅允许白名单宏”。宏失败策略会写入本地客户端队列，支持失败后停止队列、跳过当前宏、继续后续宏或暂停询问用户。宏被禁用、来源未授权或不在白名单时，系统只写入安全报告，不创建执行前备份，也不会把该宏交给本地客户端。

任务中心的“恢复”按钮会把宏执行前备份复制回原文件路径。恢复只接受 `.k12-data/backups/` 下由当前任务记录的备份文件，避免任意路径覆盖。

## 系统维护

设置页可配置自动清理临时文件、历史保留天数、日志保留天数和清理周期天数。开启自动清理后，本地服务启动时会检查上次清理时间，超过周期才执行清理。手动“清理历史”会删除超过保留期的任务、报告、日志、报告文件、输出目录、宏备份目录和图片缓存目录，但会保留文件库记录、上传源文件和外部原始文档路径。

## Windows 与 macOS 安装差异

设置页可选择本地客户端平台，并会即时刷新安装画像。Windows 安装画像优先使用 Microsoft Office COM、pywin32 和 Windows MathType 自动化；macOS 安装画像会标记 Office 自动化受限，优先走本地文件分析、人工确认和公式兜底格式。Windows 与 macOS 的 MathType 公式对象不通用，跨平台交付建议同时保留 MathML、LaTeX 或图片兜底。运行预检会对 OMML/MathType 相关任务给出兼容提示：平台专属对象模式需确认，MathML/LaTeX 或图片兜底模式通过。

## 本地 API 安全

默认监听 `127.0.0.1`，设置页的“本地安全令牌”留空时保持无令牌模式。填写令牌并保存后，前端会把令牌保存在浏览器本地存储，后续 API、上传、报告下载、图片资源和任务打包下载都会自动携带该令牌。
