## 已覆盖

- 首页/工作台：拖拽上传、拖入文件夹递归读取、文件夹上传相对层级保留、文件列表、支持格式说明、10 个快捷功能入口、最近任务列表，以及按 PRD 第 20 章组织的菜单结构页。

- 安全与隐私：设置页新增 PRD 第 13 章核查面板，覆盖文件安全、宏安全、本地通信安全、隐私保护、离线模式和私有化规划。

- 产品总结：新增 `/api/product-summary` 与设置页 PRD 第 21 章面板，汇总 13 条核心能力、四阶段产品路线和当前已落地/合同覆盖/规划中状态。

- 本地连接：支持启用本地客户端、网页唤起授权、云端同步授权、任务状态同步授权和敏感文档本地优先策略。
- 本地客户端交接：提供本地客户端运行清单、受安全令牌保护的心跳、启动请求、任务参数包和脱敏就绪接口，向本地客户端交付本地 API、唤起协议、任务选项、输入路径、预检项、本地动作队列、桌面执行计划、客户端就绪判断、输出目录、公式交付合同和同步策略；客户端就绪判断基于最近心跳的脱敏组件预检，返回当前动作所需能力、已满足能力、缺失能力和平台匹配状态。设置页通过就绪接口展示当前任务是否可交接、缺少哪些本地能力、桌面执行计划摘要和对应动作状态，不读取完整本地载荷；Windows/macOS 目标平台与心跳平台不一致时显示平台不符，阻止平台专属 MathType/Office 对象跨系统交付。公式交付合同会声明 Windows/macOS 平台、MathType 对象格式、跨平台不通用风险、兜底格式和平台专属对象写入边界。桌面执行计划会列出 Office、MathType、OMML 和宏动作的能力门槛、授权门槛、平台门槛、步骤和输出合同，同时明确网页端不直接执行原生文档动作。设置页提供本地任务交接面板，用于提示启动本地客户端、记录启动请求、查看运行清单、载荷地址、令牌/授权状态、客户端就绪状态、桌面执行计划和最近同步状态，并支持本地客户端回传平台、版本、能力摘要、任务状态、进度、输出摘要、动作级 dry-run 校验摘要和结果上传意图。
- 本地伴随 CLI：提供 `python3 -m k12.local_client` / `k12-local-client` 标准库入口，可独立读取运行清单、发送心跳、领取受令牌保护的本地任务载荷，并以 dry-run 方式同步“已接收”状态；心跳会附带 Office、MathType、LibreOffice 和 OMML 依赖的脱敏组件预检摘要。dry-run 会生成 `k12.localDryRunExecution.v1`，逐个动作记录 gate、能力门槛、步骤数量、输出类型和等待/阻塞原因。`--native-plan` 会生成 `k12.localNativeExecutionRequest.v1` 原生执行请求合同，明确 Windows 同平台执行、能力门槛、步骤和阻断原因。`--execute-file-actions` 会生成 `k12.localFileActionExecution.v1` 并执行 OMML 依赖复制等安全本地文件动作，目标必须是当前文档所在目录。该入口不执行 Office、MathType、OMML 写回或 Word 宏。
- 本地结果上传队列：提供 `/api/local-client/uploads`，按本地同步记录汇总输出摘要、上传请求、云端同步授权和脱敏路径状态，区分等待上传、已登记待云端接收、未授权和仅本地保存；POST 登记上传包清单时需要本地安全令牌和云端同步授权，可只保存输出名、大小、哈希和路径隐藏状态，也可接收 Base64 结果内容并写入受控 `cloud_uploads/{upload_id}/` 接收区；`/api/local-client/uploads/{upload_id}/manifest` 提供云端接收清单，声明包哈希、输出校验、授权状态、路径隐藏策略、内容传输模式和接收合同，设置页可从本地结果上传队列打开清单摘要。
- 网页管理：支持本地用户管理、角色权限、当前用户切换、通用模板管理、授权管理和运行预检。
- 权限管理：默认管理员具备全部本地权限，教师/学生/访客按角色授予不同能力，访客默认为只读；文件管理、报告管理、创建任务、宏任务、任务控制、用户管理、模板管理、授权管理和设置保存会进行权限检查，开启 `requireLogin` 后本地 API 会要求先登录允许登录的启用用户。
- 模板管理：支持 PPT、Word、Excel、OCR 参数和公式格式模板记录，模板路径默认按本地路径隐私策略脱敏。
- 授权管理：统一管理 Mathpix 外部上传、网页唤起本地客户端、云端同步、任务状态同步、宏执行队列和本地路径展示授权，并同步到系统设置。
- 系统异常预检：输出目录写入权限、磁盘空间、用户权限、本地客户端、客户端平台心跳、本地组件能力、Mathpix 和宏授权会写入质量检查；平台冲突或已连接客户端缺少 Office、MathType、OMML 依赖检索、宏执行等任务必需能力时进入失败清单。
- 安装画像与安装计划：设置区分 Windows 与 macOS，本地能力、安装组件、预检清单、任务分流和 MathType 兼容策略按平台展示；`/api/install-plan` 按平台返回 `.msi` / `.pkg` 安装包状态、校验要求、安装步骤、客户端心跳平台匹配状态、下载边界和 `formula_compatibility` 公式交付合同；OMML/MathType 任务预检会提示平台专属对象不通用，并在 MathML/LaTeX 或图片兜底模式下通过；目标平台与本地客户端心跳平台不一致时，预检会作为失败项写入报告，阻止平台专属 MathType/Office 对象跨系统交接。
