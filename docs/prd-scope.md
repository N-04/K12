# 首版范围映射

PRD 很完整，首版先建立可运行的产品骨架和接口合同。

## 已覆盖

- 首页/工作台：拖拽上传、拖入文件夹递归读取、文件夹上传相对层级保留、文件列表、支持格式说明、10 个快捷功能入口、最近任务列表，以及按 PRD 第 20 章组织的菜单结构页；ZIP 批量导入会统一清理 Windows/POSIX 路径穿越片段，并在解压前限制条目数、展开总大小、异常压缩比和加密成员。
- 文件校验：支持重复文件自动重命名、跳过和覆盖策略，并标记是否含图片、是否含微小图片，以及含 OMML 的 Word 是否缺少 OMML 依赖；文件列表和上传结果会展示不支持、损坏、加密、过大等校验失败原因；未通过校验的文件不会生成派生公式、宏、图片或转换产物，也不会提交到 Mathpix。
- 文件下载：支持从文件列表下载源文件、上传缓存和 ZIP 解压条目。
- 批量下载：支持按已选文件或当前文件类型打包下载源文件 ZIP。
- 文件删除：删除上传缓存和 ZIP 解压子文件记录，保留外部原始文件。
- 重新上传：支持用新上传内容替换已有文件记录，保留原 `file_id` 并重新分析文件能力；ZIP 替换会删除旧子条目和缓存，再按新压缩包重新生成受安全校验的子文件记录。
- 加密文件：识别 PDF 的 `/Encrypt` 标记以及现代 Office 加密文档使用的 OLE Compound File 容器，避免把加密 DOCX/PPTX/XLSX 误报为损坏 ZIP；识别后提示输入密码，密码仅保存在当前本地会话。
- 文档预览：支持 Word、PPT、Excel、PDF、图片、ZIP 的结构化页面预览、对象列表、告警摘要、搜索、告警/对象点击定位、命中高亮、翻页和缩放；页段会显示公式、OMML、MathType、宏、微小图片和低置信度对象标记，标记也可参与搜索定位。
- 转换前后对比预览：报告可对比源文件和成功转换产物的页段、对象数量、告警和预览摘要。
- 转换异常：本地转换与 Mathpix 下载后校验 OOXML 必需部件、ZIP CRC、PDF 头尾和公式 ZIP 路径/解压体积边界，无法打开或不完整的输出不会暴露下载 URL，会被删除并将任务、报告和失败清单标记为失败。
- 下载安全：产物下载与任务打包仅接受任务最新报告登记且具有大小、SHA-256 的成功产物，并在读取时复验任务输出根目录、格式、实际字节数和内容哈希；失败、越界、生成后被任意有效文件替换或旧重试轮次的产物不进入 ZIP。历史报告和日志仍保留在任务包中用于审计。
- 下载读取一致性：路径与格式初检后读取文件字节快照，再对快照复验登记大小和 SHA-256；单文件响应和任务 ZIP 使用同一已验证快照，校验完成后发生的文件替换不会进入下载内容。
- 报告文件完整性：每次报告生成或状态重写都会为 JSON、HTML、PDF、XLSX、TXT、失败 CSV 登记实际大小和 SHA-256；下载与任务包读取时复验受管目录、大小和哈希，生成后被替换的报告文件不会继续暴露。
- 安装包读取一致性：Windows `.msi` 与 macOS `.pkg` 下载在平台和目录边界校验后读取快照，并复验描述符大小、SHA-256；校验后被替换的安装包不会进入响应，哈希响应头与实际响应体保持一致。
- 源文件安全：上传缓存、重新上传、压缩包解压条目和注册时存在的外部文件登记大小、SHA-256；受管文件下载时解析真实路径并校验 `uploads/` 根目录，单下载与批量 ZIP 读取快照后复验大小、哈希，拒绝越界或登记后被替换的文件，批量失败写入 manifest。
- 处理前源文件复验：每次任务执行在对象分析、Mathpix 提交和格式转换之前核对源文件登记大小、SHA-256；被替换的有效格式文件也会持久化为校验失败，进入报告失败清单且不生成 artifact。
- 任务输入快照：复验通过的输入复制到当前任务专属 `.inputs` 并再次核对大小、SHA-256；服务端内容分析/转换和本地 Office 打开使用该快照，原文件变化不会改变本轮读取内容；OMML 依赖复制、宏备份和恢复仍使用原文档路径。
- 旧版 Office 预检：`.doc/.dot/.xls/.ppt` 实际读取 OLE/CFB 文件头，损坏签名、字节序或扇区字段进入文件校验失败，加密流进入密码提示；未经本地 Office 解析前不伪造结构数量或宏/公式检测结果。
- 旧格式任务分流：有效 OLE 输入的 Word/PPT/Excel 转换自动解析为 `local` 模式，不交给 OOXML ZIP 转换器；任务、报告、质量检查和本地载荷区分“待本地执行”与真实失败，不在原生结果回传前宣称转换成功。
- 旧格式结果对账：含 pending artifact 的任务不接受无证据的 `completed`；必须回传原生 Office 成功动作、文件 ID/目标格式匹配的输出，并通过任务目录边界和内容完整性校验。对账成功后任务进度升为 100%，报告成功/待处理计数、质量检查和下载 artifact 同步刷新。
- 重试产物新鲜度：每轮任务记录独立的高精度开始时间；本地 Office 回传文件必须在当前轮次开始后生成或更新，旧轮次遗留文件即使格式有效也不能登记为本轮成功产物。
- 本地输出内容绑定：客户端输出摘要必须携带格式合法的非负文件大小和 SHA-256，待处理 Office 产物只有在声明值与服务端对受管文件实测字节数、复算哈希一致时才能升级为成功；报告保存实测值而不盲信客户端摘要。
- 本地失败对账：`failed` 同步将待处理 artifact 终结为 `local_execution_failed`，重算报告成功/失败/待处理计数，并把本地 Office 原因写入转换输出失败行、质量检查和 CSV。
- 本地取消对账：任务中心主动取消或客户端 `cancelled` 同步将待处理 artifact 终结为 `local_execution_cancelled`，独立记录取消数量并清零待处理数量，失败清单和失败 CSV 不把取消误报为错误。
- 本地同步状态保护：成功、失败、已取消任务不能被迟到的客户端消息改写为其他状态，同终态重复完成消息保持幂等；处理中不能退回待处理，已暂停和已中断不能通过同步入口绕过继续或重试控制；处理进度采用单调递增规则，乱序或较旧的回传不会让任务进度倒退。
- 排版校正：支持在报告页按报告记录页码、标题层级、表格结构、图片位置、公式位置和公式编号问题，保存修复前后描述、建议和处理状态；公式位置丢失时会写入异常位置并进入失败清单和质量检查。
- 文件处理页：筛选、任务类型、可调整顺序的处理流程、参数、日志、下载入口、报告入口、文件列表大小、页/页签指标、MathType/图片/微小图/OMML 缺失能力标记、预览/转换/检索/下载/报告/替换/删除操作和可见的文件详情/结果预览面板；报告入口读取 `/api/files/{file_id}/reports`，按单个文件跳转并高亮关联报告。
- 安全与隐私：设置页新增 PRD 第 13 章核查面板，覆盖文件安全、宏安全、本地通信安全、隐私保护、离线模式和私有化规划。
- 兼容性矩阵：设置页新增 PRD 第 15 章核查面板，覆盖操作系统、Office、公式、宏和模式兼容性，并明确 Windows/macOS MathType 对象不通用的兜底策略。
- 技术架构：新增 `/api/architecture` 与设置页 PRD 第 16 章面板，结构化展示当前本地 API、静态前端、SQLite/文件目录、接口合同和后续 FastAPI/Django/队列/真实文档引擎接入边界。
- 开放 API：新增 `/api/api-catalog` 与设置页接口目录，按 V3.0 API 接口开放规划列出本地 API 的方法、路径、鉴权要求、敏感接口和本地任务载荷保护边界。
- 产品总结：新增 `/api/product-summary` 与设置页 PRD 第 21 章面板，汇总 13 条核心能力、四阶段产品路线和当前已落地/合同覆盖/规划中状态。
- 智能增强规划：新增 `/api/enhancement-plan` 与设置页 V3.0 面板，拆分 AI 排版修复、智能模板套用、私有化部署、开放 API 和质量反馈闭环的输入来源、接入状态和风控约束，明确 AI 排版与模板套用仍为规划能力。
- Word 处理：转换页提供 Word 文件预览、公式/OMML/MathType 检测、宏检测、报告入口、公式预检、OMML 转 MathType、OMML 文件检索、宏顺序和 MathType 格式化。
- OMML 依赖：支持检测到 Word 自带公式后的 MathType 转换确认记录，支持当前文档目录、运行目录、自定义路径检索和手动 OMML 文件指定，按策略复制，更新文件缺失状态并生成报告记录。
- OMML 复制完整性：自动检索或手动指定的依赖先读取源快照并登记大小、SHA-256，复制后复验目标字节内容并登记目标大小、SHA-256；跳过已有目标也记录实测哈希，复制不一致会标记失败。
- OMML 校正：支持按报告记录转换失败、保留 OMML、重新转换、已修复和手动指定依赖路径，主界面 OMML 依赖卡片可快捷标记保留、重新转换、已修复或指定依赖文件；重新转换会进入本地客户端 `retry_queued` 动作和 `omml.retry_conversion` 桌面计划步骤，并可导出 OMML 转换失败清单 CSV，报告删除时会清理相关校正记录。
- 宏处理：支持宏库选择、按名称/来源/用途/最近使用筛选、宏详情面板、通过拖拽手柄或上/下移图标调整执行顺序、顺序模板保存/加载/删除、风险确认、宏检测开关、按来源授权、禁用宏执行队列、白名单宏控制、执行超时、批量执行控制、失败后停止/跳过/继续/询问策略、执行前备份、备份恢复、宏执行日志、从宏执行报告卡片重跑指定宏、载入报告宏顺序并调整后重新执行、导出宏执行失败清单 CSV 和待本地客户端执行报告；Word 宏检测读取 OOXML 中实际的 `word/vbaProject.bin` 部件，而不是仅凭 `.docm` / `.dotm` 扩展名判断，空宏容器不会误报，错误扩展名中的 VBA 部件也不会漏报；验收矩阵还会用临时文件验证文档/模板宏检测和同一宏顺序应用到多个 Word 文件，真实 VBA 模块枚举和执行仍需本地客户端。
- 宏备份完整性：执行前备份登记实际大小和 SHA-256；恢复时复验受管备份目录、字节快照大小与哈希，备份被替换或记录不完整时拒绝写回原文档并记录恢复失败。
- 微小图片：支持 Word/PPT/Excel OOXML 媒体提取，也支持读取 PDF 图片 XObject 的宽高、Filter 和可导出流；统一进行尺寸/面积阈值判定、页眉页脚/水印/透明/重复图片过滤、缩略图资源，以及记录宽高、面积、图片格式、疑似类型、人工确认类型、页眉页脚、水印、透明、重复状态、重复判断状态、导出状态和异常兜底的图片清单报告；图片提取失败会进入失败清单和质量检查，重复判断失败或无法判断时会保留原始结果。
- 微小图片操作：支持按疑似类型、文件来源、位置关键词、面积和重复状态筛选，支持缩略图网格与详情面板，详情面板集中展示图片预览、位置、尺寸、面积、置信度、类型判断、标注状态和导出状态；支持单张查看/导出、导出失败后从来源文档重新导出、定位回来源文件预览、定位失败标记为“位置未知”、按报告导出图片 ZIP 和微小图片清单 XLSX、确认图片类型、标记误判、删除待处理和替换待处理；替换操作会保存用户选择的替换图片素材、大小、hash 和受令牌保护的素材 URL，真实源文档改写仍交给本地客户端。
- 图片资源完整性：提取和重新导出的图片登记实际大小、SHA-256，替换素材登记大小、SHA-256 和标注归属；单图、替换素材和报告图片 ZIP 只读取已登记且快照复验一致的资源，登记后被替换或目录中未登记的文件不会下载。
- OCR 设置：支持语言、文字 OCR、公式 OCR、表格 OCR、精度模式和速度模式；Mathpix 请求只提交规范 `conversion_formats` 等真实参数，K12 OCR 设置进入作业审计元数据。
- PPT/PDF/Excel：转换任务入口和报告摘要。

- Excel 转 Word/PPT：按全部工作表、当前工作表、选区或 API 指定 sheet 提取工作表、单元格、公式、图表、图片和批注摘要，并支持保留公式、仅保留计算结果或拆分工作表为多个文件，生成可下载的 DOCX/PPTX 产物。
- 转换设置：支持模板、模式、PDF 精度、Excel 范围、Word 转 PPT 每页字数、自动分页、目录页、保留公式、先转 MathType、演讲者备注、自动美化、PPT 转 Word 的 Word 模板、目录开关、备注提取、图片提取和公式提取，以及保留图片/表格/页眉页脚/脚注尾注/批注/修订标记偏好，并写入转换输出报告。
